# Chess Notes

Personal chess notes in a compact, two-column LaTeX layout.

- [Minor-Piece Checkmate Patterns](Endgame/minor-piece-checkmate-patterns.tex)
- [Reusable template](Templates/template.tex)

Build with `latexmk -xelatex <file>.tex`.

**Diagram key:** Blue numbered arrows show White's moves. Red squares show current threats; yellow squares show future threats; green squares show the black king's retreat squares.
